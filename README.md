Markdown files in the folder named articles are the basis for the content.
The words in a title and abstract (defined in the file index.json) are the basis for the search function and the "front page". 
markdown-it is the basis for parsing markdown into html, together also with the styling from the css file and javascript code in the app.js file. 
This solution will run on any web server.
